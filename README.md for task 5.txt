# Task 5 – SQL Joins

## Objective
To practice combining data from multiple related tables using different types of joins.

## Join Types Used

- INNER JOIN – Displays matching records from both tables.
- LEFT JOIN – Displays all records from left table and matched records from right.
- RIGHT JOIN – Simulated using LEFT JOIN (SQLite limitation).
- FULL OUTER JOIN – Implemented using UNION.
- SELF JOIN – Joining a table with itself.

## Concepts Covered
- Table Relationships
- Foreign Keys
- Data Merging
- Query Optimization Basics
